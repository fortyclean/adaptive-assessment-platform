# Store Screenshots and Promo Plan

Version: 1.0.72

## Screenshot Set

1. Student dashboard: show progress, current learning path, and next action.
2. Adaptive assessment: show question, progress, timer, and clear answer options.
3. Results screen: show score, strengths, weaknesses, and next recommendation.
4. Micro-learning: show short lesson cards tied to weak skills.
5. Teacher dashboard: show classroom overview and assessment status.
6. Assessment creation/publishing: show teacher workflow and classroom assignment.
7. Admin dashboard: show users, classrooms, reports, and alerts.
8. Notifications: show in-app notifications and read/unread states.

## Promo Video Outline

Duration: 20-30 seconds.

1. Start with the problem: students need feedback beyond a final score.
2. Show adaptive assessment reacting to answers.
3. Show instant result and skill breakdown.
4. Show micro-learning recommendation.
5. Show teacher/admin dashboards.
6. End with "Adaptive Mastery: smarter assessment for every learner."

## Production Rules

- Use real app screens, not mockups unrelated to the build.
- Hide student personal data or use demo accounts only.
- Capture both Arabic RTL and English LTR examples once localization is complete.
- Verify screenshots on small phone and tablet layouts.
