## App Name

Adaptive Mastery

## Short Description

Adaptive assessments, student analytics, and micro-learning for schools.

## Full Description

Adaptive Mastery helps schools deliver smarter assessments and clearer learning insights. Students can take adaptive tests, review progress, receive targeted micro-learning recommendations, and track points, challenges, and achievements. Teachers can create assessments, publish them to classrooms, review reports, and identify skill gaps. Administrators can manage users, classrooms, assignments, reports, and audit-sensitive actions.

Core features:

- Adaptive assessments that respond to student performance.
- Student progress, analytics, recommendations, and micro-learning.
- Teacher assessment creation, publishing, reports, and class insights.
- Admin user, classroom, and school reporting tools.
- Arabic-first RTL experience with English localization foundation.
- Secure sessions, role-based access, and production readiness checks.
