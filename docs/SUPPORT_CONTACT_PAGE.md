# Support and Contact Page Draft

Version: 1.0.72

## Support Channels

- Email: support@adaptivemastery.app
- Response target: 2 business days
- Supported topics: login, account approval, assessment access, classroom assignment, reports, notifications, and data privacy requests.

## Required Store Information

Before public launch, replace the placeholder email with the final support address and publish:

- Privacy Policy URL
- Terms of Use URL
- Support/contact URL
- Data deletion request instructions
- School administrator escalation path

## Data Deletion Request Template

Users or schools should provide:

- Account username or email
- School name
- Role: student, teacher, or admin
- Requested action: export, correction, deletion, or deactivation
- Proof of authorization for school-wide requests

Do not request passwords, access tokens, or screenshots containing sensitive student data.
