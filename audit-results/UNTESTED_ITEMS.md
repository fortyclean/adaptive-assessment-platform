# عناصر لم يمكن اختبارها فعلياً

- تشغيل التطبيق وتثبيته على هاتف Android: لا يوجد جهاز Android متصل أو محاكي متاح.
- سيناريوهات الواجهة الحية ولقطات الشاشة: تتطلب هاتفاً/محاكياً.
- API الحي والخادم: الخادم لا يستمع على 127.0.0.1:3000، وتشغيله يتطلب MongoDB وRedis وملف بيئة اختبار آمن.
- بناء iOS: غير مدعوم من بيئة Windows الحالية.
- قياسات الأداء على جهاز (زمن الإطلاق، الذاكرة، المعالج): تتطلب جهاز Android متاحاً.
- فحص ثغرات الحزم المتصل بالشبكة: لم تنتج عنه نتيجة قابلة للتوثيق ضمن هذه الجلسة.
