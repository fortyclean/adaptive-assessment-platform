# مهام إصدار 1.0.25 - تعزيز تجربة المشرف التشغيلية

## الهدف

إكمال طبقة التلميع التشغيلي لشاشات المشرف بعد إصدار 1.0.24، مع رفع الإصدار وتوثيق التحسينات دون تغيير الهوية البصرية الأصلية.

## قائمة المهام

- [x] إضافة حالة مزامنة ووقت آخر حفظ في إعدادات المؤسسة.
- [x] التحقق من بريد المؤسسة ورقم التواصل قبل الحفظ.
- [x] إضافة فلتر الفصل في إدارة المستخدمين.
- [x] عرض أسماء الفصول المرتبطة داخل بطاقة المستخدم.
- [x] إظهار اسم المستخدم بوضوح داخل نافذة تعديل المستخدم.
- [x] إضافة بحث وفلاتر تشغيلية في إدارة الفصول.
- [x] تحسين بطاقات الفصول بملخص المعلم وأسماء الطلاب المتاحة.
- [x] إضافة اختيار صيغة تصدير تقارير المدرسة بين JSON و CSV.
- [x] عرض ملخص دائم للفلاتر وآخر تحديث في تقارير المدرسة.
- [x] توحيد مسارات شاشات المشرف على `AppRoutes`.
- [x] إضافة اختبارات حفاظ موجهة لتحسينات 1.0.25.
- [x] تحديث رقم الإصدار وسجل الإصدارات داخل التطبيق والأدلة.
